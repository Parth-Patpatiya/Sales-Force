# Introduction
## The Salesforce AI Agent: Agentforce 
Agentforce is Salesforce's AI platform for building and deploying autonomous AI agents that handle tasks across sales, service, and other enterprise workflows.

Atlas Reasoning Engine: Breaks user requests into logical steps, chooses the right actions, and decides when to escalate to a human. 

Agentforce Builder: A low-code tool that lets creators set up agents using natural language descriptions instead of rigid decision trees.

Data Integration: Connects with Salesforce Data Cloud and external sources using Retrieval-Augmented Generation (RAG) to ground answers in real-time, trusted company data. 

You can dive deep and learn all the prerequisites at [Parth-git](https://www.salesforce.com/agentforce/how-it-works/video/)
